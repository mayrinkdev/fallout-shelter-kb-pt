# Base de conhecimento: Fallout Shelter (pt-BR)

Base de fatos sobre o jogo **Fallout Shelter**, escrita para uma IA ler e responder dúvidas de jogo com precisão.

## Versão e revisão

| Item | Valor |
|---|---|
| Última revisão | 2026-11-25 |
| Versão do jogo no vault do usuário | **não informada** (preencher com a versão em Configurações do jogo) |
| Versão mais recente citada pela wiki | 2.7.0, lançada em outubro de 2026 (`confirmado` · wiki: https://fallout.fandom.com/wiki/Fallout_Shelter) |

Os fatos `testado` valem para a versão instalada no vault do usuário. Se a versão mudar, revise esses fatos.

## Como a IA deve usar esta base

1. **Responda só com o que está aqui.** Se a resposta não estiver na base, diga que não sabe. Não complete com conhecimento de outros jogos da série Fallout, porque as mecânicas são diferentes.
2. **Cite o arquivo** de onde tirou a resposta (ex.: "segundo `salas.md`…").
3. **Informe o nível de certeza** do fato usado:
   - `confirmado`: vem da wiki ou da tela do jogo. Pode afirmar.
   - `testado`: o usuário testou no próprio vault. Pode afirmar e dizer que foi testado.
   - `não verificado`: **desconfie**. Diga claramente que não está confirmado e sugira como verificar.
4. **Consulte `erros-comuns.md` antes de responder.** Ele lista afirmações que já se mostraram erradas.
5. Quando duas fontes divergem, mostre as duas e diga qual é qual. Não escolha uma em silêncio.

## Formato de cada fato

Cada fato termina com uma etiqueta no formato:

> `nível` · fonte: wiki (URL) | tela do jogo | teste do usuário

Exemplo: `confirmado` · fonte: wiki (https://fallout.fandom.com/wiki/Medbay)
